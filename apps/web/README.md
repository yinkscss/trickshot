# @trickshot/web

Canvas2D pitch client (`client=canvas2d_pitch`) — vanilla HTML + `CanvasRenderingContext2D` + Nunito + `requestAnimationFrame`. Visual language matches [docs/animation-pitch.html](../../docs/animation-pitch.html). Physics/logic authority stays in `@trickshot/physics` and `@trickshot/logic`. PWA wraps this canvas app later — no Phaser.

```bash
# from repo root
npm install
npm run dev:web
```
